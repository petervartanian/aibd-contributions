# AI Benefits Database contributions

Suggest a source, correct an entry, or propose a new benefit for the [AI Benefits Database](https://petervartanian.xyz/aibd/).

[Open a contribution](https://github.com/petervartanian/aibd-contributions/issues/new?template=contribution.md). GitHub assigns a tracking number when you submit it. Contributions and replies are public, and a GitHub account is required.

Include the case number when there is one, the change that you propose, and the original evidence that supports it. A source link and a page or section help the editor verify the contribution.

Peter H. Vartanian reviews contributions before publication. An open submission is awaiting a decision. Closing a submission does not by itself mean that it was accepted; the closing comment records the outcome.

For private material, [email Peter](mailto:peter.vartanian@icloud.com) instead of posting it here. Do not include private personal information in a public submission.
